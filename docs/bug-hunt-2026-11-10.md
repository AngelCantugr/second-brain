## Suspicions, not proven

- `vector_store.py:122-123` deletes Qdrant's `.lock` on startup, so a CLI sync run while the MCP server is up can open the same local store concurrently.
- `sync_state.py` / `keyword_store.py`: `with sqlite3.connect(...)` commits but never closes; connections are left to the garbage collector.
- `LinkResolver` compares names with `.lower()` only, so an NFC title and an NFD link do not match (iCloud/HFS filenames).
- `doc_roles` globs are case-sensitive: `changelog.md` is tracked as `reference`, not `history`.
- `sources.py:179`: a non-UTF-8 git path decoded with `surrogateescape` would fail later at `encode("utf-8")`.
